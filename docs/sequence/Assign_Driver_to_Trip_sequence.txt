@startuml
title Assign Driver to Trip - Sequence Diagram

hide footbox
skinparam sequenceMessageAlign center
skinparam responseMessageBelowArrow true
skinparam ParticipantPadding 25
skinparam BoxPadding 10

actor Admin
participant "Admin Web App" as Web
participant "AdminController" as AssignmentController
participant "AdminModel" as AssignmentRepository
database "TripSchedule Collection" as ScheduleDB
database "DriverShiftAssignment Collection" as DriverAssignDB

note over AssignmentController
Driver assignment to a trip is performed by updating TripSchedule.driver through PUT /api/admin/trip-schedules/:scheduleId, not by a dedicated AssignmentController.
end note

Admin -> Web: 1: Select driver for trip schedule
activate Web
Web -> AssignmentController: 1.1: PUT /api/admin/trip-schedules/:scheduleId
activate AssignmentController
AssignmentController -> AssignmentRepository: 1.2: findTripScheduleById(scheduleId)
activate AssignmentRepository
AssignmentRepository -> ScheduleDB: 1.2.1: find current schedule
activate ScheduleDB
ScheduleDB --> AssignmentRepository: 1.2.2: schedule or null
deactivate ScheduleDB
AssignmentRepository --> AssignmentController: 1.3: schedule
deactivate AssignmentRepository
alt [trip schedule not found]
    AssignmentController --> Web: 1.4.1: 404 Trip schedule not found
else [schedule can be edited]
    AssignmentController -> AssignmentRepository: 1.5: findEligibleDriverShiftAssignment(payload)
    activate AssignmentRepository
    AssignmentRepository -> DriverAssignDB: 1.5.1: find driver shift covering trip time
    activate DriverAssignDB
    DriverAssignDB --> AssignmentRepository: 1.5.2: eligible assignment or null
    deactivate DriverAssignDB
    AssignmentRepository --> AssignmentController: 1.6: driver eligibility
    deactivate AssignmentRepository
    alt [driver unavailable]
        AssignmentController --> Web: 1.7.1: 409 driver has no matching shift
    else [driver available]
        AssignmentController -> AssignmentRepository: 1.8: findScheduleAssignmentConflicts(payload, scheduleId)
        activate AssignmentRepository
        AssignmentRepository -> ScheduleDB: 1.8.1: check overlapping driver assignment
        activate ScheduleDB
        ScheduleDB --> AssignmentRepository: 1.8.2: conflicts
        deactivate ScheduleDB
        AssignmentRepository --> AssignmentController: 1.9: conflict list
        deactivate AssignmentRepository
        alt [schedule conflict detected]
            AssignmentController --> Web: 1.10.1: 409 assignment conflict
        else [assignment available]
            AssignmentController -> AssignmentRepository: 1.11: updateTripScheduleById with driver
            activate AssignmentRepository
            AssignmentRepository -> ScheduleDB: 1.11.1: save driver on TripSchedule
            activate ScheduleDB
            ScheduleDB --> AssignmentRepository: 1.11.2: updated schedule
            deactivate ScheduleDB
            AssignmentRepository --> AssignmentController: 1.12: updated schedule
            deactivate AssignmentRepository
            AssignmentController --> Web: 1.13: 200 schedule updated
        end
    end
end
deactivate AssignmentController
Web --> Admin: 1.14: Show driver assignment
deactivate Web
@enduml
