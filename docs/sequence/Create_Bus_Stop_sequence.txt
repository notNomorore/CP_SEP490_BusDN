@startuml
title Create Bus Stop - Sequence Diagram

hide footbox
skinparam sequenceMessageAlign center
skinparam responseMessageBelowArrow true
skinparam ParticipantPadding 25
skinparam BoxPadding 10

actor Admin
participant "Admin Web App" as Web
participant "BusStopController" as BusStopController
participant "BusStopService" as BusStopService
participant "bus-stop.repository" as BusStopRepository
database "RouteStation Collection" as StopDB
participant "MapService" as MapService

note over BusStopController,BusStopService
busStopRoutes.js defines POST /api/bus-stops, but app.js currently comments out app.use('/api/bus-stops', busStopRoutes). The admin workflow also supports POST /api/admin/stations through AdminController.
end note

Admin -> Web: 1: Submit bus stop form
activate Web
Web -> BusStopController: 1.1: POST /api/bus-stops
activate BusStopController
BusStopController -> BusStopService: 1.2: createBusStop(payload)
activate BusStopService
BusStopService -> BusStopService: 1.3: normalizeStopPayload and validateImportedStop
alt [coordinates missing and address provided]
    BusStopService -> MapService: 1.4.1: geocodeAddress(address)
    activate MapService
    MapService --> BusStopService: 1.4.2: coordinates or geocode error
    deactivate MapService
end
alt [validation failed]
    BusStopService --> BusStopController: 1.5.1: validation error
else [payload valid]
    BusStopService -> BusStopRepository: 1.6: create station
    activate BusStopRepository
    BusStopRepository -> StopDB: 1.6.1: save RouteStation
    activate StopDB
    StopDB --> BusStopRepository: 1.6.2: saved station
    deactivate StopDB
    BusStopRepository --> BusStopService: 1.6.3: station
    deactivate BusStopRepository
    BusStopService --> BusStopController: 1.7: stop created
end
deactivate BusStopService
alt [validation or geocode failed]
    BusStopController --> Web: 1.8.1: 400 error
else [created]
    BusStopController --> Web: 1.8.2: 201 Bus stop created successfully
end
deactivate BusStopController
Web --> Admin: 1.9: Show stop save result
deactivate Web
@enduml
