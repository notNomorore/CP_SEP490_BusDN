@startuml
title Define Route Path - Sequence Diagram

hide footbox
skinparam sequenceMessageAlign center
skinparam responseMessageBelowArrow true
skinparam ParticipantPadding 25
skinparam BoxPadding 10

actor Admin
participant "Admin Web App" as Web
participant "Admin Web App" as PathEditor
participant "AdminController" as RouteController
participant "AdminModel" as RouteRepository
database "BusRoute Collection" as RouteDB
database "RouteStation Collection" as StopDB

note over PathEditor
The map/path logic is primarily in frontend Leaflet components and routeWorkflowUtils. No backend MapService class exists.
end note

Admin -> Web: 1: Define outbound and inbound path
activate Web
Web -> PathEditor: 1.1: validate stops, coordinates, sequence, and polyline
activate PathEditor
alt [invalid path or stop sequence]
    PathEditor --> Web: 1.2.1: show path validation errors
else [path valid]
    PathEditor --> Web: 1.2.2: build route payload with orderedStops and polylinePath
end
deactivate PathEditor
Web -> RouteController: 1.3: PUT /api/admin/routes/:routeId
activate RouteController
RouteController -> RouteController: 1.4: normalizeRoutePayload and validateRoutePayload
alt [backend validation failed]
    RouteController --> Web: 1.5.1: 400 Route validation failed
else [backend validation passed]
    RouteController -> RouteRepository: 1.6: updateRouteById(routeId, path payload)
    activate RouteRepository
    RouteRepository -> RouteDB: 1.6.1: persist ordered stops and polylinePath
    activate RouteDB
    RouteDB --> RouteRepository: 1.6.2: updated route or null
    deactivate RouteDB
    RouteRepository -> StopDB: 1.6.3: sync station route assignments if published
    activate StopDB
    StopDB --> RouteRepository: 1.6.4: sync complete
    deactivate StopDB
    RouteRepository --> RouteController: 1.7: route or null
    deactivate RouteRepository
    alt [route not found]
        RouteController --> Web: 1.8.1: 404 Route not found
    else [path saved]
        RouteController --> Web: 1.8.2: 200 Route updated successfully
    end
end
deactivate RouteController
Web --> Admin: 1.9: Render updated route preview on map
deactivate Web
@enduml
