@startuml
title Export Financial Reports - Sequence Diagram

hide footbox
skinparam sequenceMessageAlign center
skinparam responseMessageBelowArrow true
skinparam ParticipantPadding 25
skinparam BoxPadding 10

actor Admin
participant "Admin Web App" as AdminWebApp
participant "RevenueController" as RevenueController
participant "RevenueService" as RevenueService
participant "TransactionRepository" as TransactionRepository
database "Transaction Collection" as TransactionCollection
participant "ExportService" as ExportService

note over ExportService
No separate ExportService module exists.
RevenueReportService builds PDF or Excel buffers internally.
end note

Admin -> AdminWebApp: 1: Export financial report
activate AdminWebApp
AdminWebApp -> RevenueController: 1.1: GET /api/admin/revenue/export?format=pdf|excel
activate RevenueController
RevenueController -> RevenueService: 1.2: exportFinancialReport(filters, admin)
activate RevenueService
RevenueService -> TransactionRepository: 1.3: retrieve report events
activate TransactionRepository
TransactionRepository -> TransactionCollection: 1.3.1: query transactions, PromotionUsage, travel history
activate TransactionCollection
TransactionCollection --> TransactionRepository: 1.3.2: export event data
deactivate TransactionCollection
TransactionRepository --> RevenueService: 1.3.3: report events
deactivate TransactionRepository

alt [invalid export format]
    RevenueService --> RevenueController: 1.4: export format error
    RevenueController --> AdminWebApp: 1.5: 400 Export format must be pdf or excel
else [export generation failed]
    RevenueService -> ExportService: 1.4: build export buffer
    activate ExportService
    ExportService --> RevenueService: 1.4.1: generation error
    deactivate ExportService
    RevenueService --> RevenueController: 1.5: export failed
    RevenueController --> AdminWebApp: 1.6: 500 Export failed
else [export successful]
    loop 1.4: Build report, ticket sales, and peak hour sections
        RevenueService -> RevenueService: 1.4.1: aggregate export section
        activate RevenueService
        RevenueService --> RevenueService: 1.4.2: section data
        deactivate RevenueService
    end
    RevenueService -> ExportService: 1.5: buildPdf or buildExcel
    activate ExportService
    ExportService --> RevenueService: 1.5.1: file buffer, content type, filename
    deactivate ExportService
    RevenueService --> RevenueController: 1.6: exported report
    RevenueController --> AdminWebApp: 1.7: 200 Download file
end
deactivate RevenueService
deactivate RevenueController
AdminWebApp --> Admin: 1.8: Save financial report file
deactivate AdminWebApp

@enduml
