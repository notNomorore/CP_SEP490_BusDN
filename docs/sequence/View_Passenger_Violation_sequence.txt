@startuml
title View Passenger Violation - Sequence Diagram

hide footbox
skinparam sequenceMessageAlign center
skinparam responseMessageBelowArrow true
skinparam ParticipantPadding 25
skinparam BoxPadding 10

actor Admin
participant "Admin Web App" as AdminWebApp
participant "ViolationController" as ViolationController
participant "ViolationService" as ViolationService
participant "ViolationRepository" as ViolationRepository
database "Violation Collection" as ViolationCollection
participant "UserRepository" as UserRepository
database "User Collection" as UserCollection

note over ViolationController, ViolationService
Implemented as PassengerComplianceController.listViolations/getViolation
and PassengerComplianceService at /api/admin/passenger-violations.
end note

Admin -> AdminWebApp: 1: View passenger violations
activate AdminWebApp
AdminWebApp -> ViolationController: 1.1: GET /api/admin/passenger-violations
activate ViolationController
ViolationController -> ViolationService: 1.2: listViolations(filters, admin)
activate ViolationService
ViolationService -> ViolationRepository: 1.3: query violations by passenger, route, severity, status, date
activate ViolationRepository
ViolationRepository -> ViolationCollection: 1.3.1: find passenger violations and statistics
activate ViolationCollection
ViolationCollection --> ViolationRepository: 1.3.2: violation records and counts
deactivate ViolationCollection
ViolationRepository --> ViolationService: 1.3.3: violation data
deactivate ViolationRepository
ViolationService -> UserRepository: 1.4: populate passenger and reporter
activate UserRepository
UserRepository -> UserCollection: 1.4.1: query users
activate UserCollection
UserCollection --> UserRepository: 1.4.2: passenger and reporter summaries
deactivate UserCollection
UserRepository --> ViolationService: 1.4.3: safe user data
deactivate UserRepository

alt [violation not found]
    ViolationService --> ViolationController: 1.5: empty violation list
    ViolationController --> AdminWebApp: 1.6: 200 No violations
else [violations available]
    ViolationService --> ViolationController: 1.5: violations with pagination and statistics
    ViolationController --> AdminWebApp: 1.6: 200 Passenger violations
end
deactivate ViolationService
deactivate ViolationController
AdminWebApp --> Admin: 1.7: Display violation records
deactivate AdminWebApp

@enduml
