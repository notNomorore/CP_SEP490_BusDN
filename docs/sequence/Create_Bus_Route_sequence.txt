@startuml
title Create Bus Route - Sequence Diagram

hide footbox
skinparam sequenceMessageAlign center
skinparam responseMessageBelowArrow true
skinparam ParticipantPadding 25
skinparam BoxPadding 10

actor Admin
participant "Admin Web App" as Web
participant "AdminController" as RouteController
participant "AdminModel" as RouteRepository
database "BusRoute Collection" as RouteDB
database "RouteStation Collection" as StopDB

note over RouteController,RouteRepository
Routes are implemented through AdminController/AdminModel and BusRoute, not separate RouteService or RouteRepository classes.
end note

Admin -> Web: 1: Save new route draft or published route
activate Web
Web -> RouteController: 1.1: POST /api/admin/routes
activate RouteController
RouteController -> RouteController: 1.2: normalize route payload and validate stops/path
alt [validation failed]
    RouteController --> Web: 1.3.1: 400 Route validation failed
else [validation passed]
    RouteController -> RouteRepository: 1.4: createRoute(payload)
    activate RouteRepository
    RouteRepository -> RouteDB: 1.4.1: save BusRoute
    activate RouteDB
    alt [duplicate route code]
        RouteDB --> RouteRepository: 1.4.2: duplicate key error
        RouteRepository --> RouteController: 1.4.3: duplicate key error
    else [route saved]
        RouteDB --> RouteRepository: 1.5.1: saved route
        RouteRepository -> StopDB: 1.5.2: syncRouteStationAssignments(route)
        activate StopDB
        StopDB --> RouteRepository: 1.5.3: station assignments synced
        deactivate StopDB
        RouteRepository --> RouteController: 1.5.4: created route
    end
    deactivate RouteDB
    deactivate RouteRepository
    alt [duplicate route code]
        RouteController --> Web: 1.6.1: 409 Route code already exists
    else [created]
        RouteController --> Web: 1.6.2: 201 Route created successfully
    end
end
deactivate RouteController
Web --> Admin: 1.7: Show route save result
deactivate Web
@enduml
