@startuml
title Reconcile Walk-in Revenue - Sequence Diagram

hide footbox
skinparam sequenceMessageAlign center
skinparam responseMessageBelowArrow true
skinparam ParticipantPadding 25
skinparam BoxPadding 10

actor Admin
participant "Admin Web App" as AdminWebApp
participant "RevenueController" as RevenueController
participant "RevenueService" as RevenueService
participant "WalkInTicketRepository" as WalkInTicketRepository
database "Walk-in Ticket Collection" as WalkInTicketCollection
participant "ShiftRevenueRepository" as ShiftRevenueRepository
database "Shift Revenue Collection" as ShiftRevenueCollection

note over RevenueController, RevenueService
Implemented under WalkInTicketController.reconcileRevenue and WalkInTicketService.reconcileRevenue
at GET /api/admin/walkin-revenue/reconciliation.
end note

Admin -> AdminWebApp: 1: Reconcile walk-in revenue
activate AdminWebApp
AdminWebApp -> RevenueController: 1.1: GET /api/admin/walkin-revenue/reconciliation
activate RevenueController
RevenueController -> RevenueService: 1.2: reconcileRevenue(filters, admin)
activate RevenueService
RevenueService -> WalkInTicketRepository: 1.3: read completed walk-in tickets
activate WalkInTicketRepository
WalkInTicketRepository -> WalkInTicketCollection: 1.3.1: query walk-in tickets by shift, route, date
activate WalkInTicketCollection
WalkInTicketCollection --> WalkInTicketRepository: 1.3.2: ticket totals
deactivate WalkInTicketCollection
WalkInTicketRepository --> RevenueService: 1.3.3: expected revenue
deactivate WalkInTicketRepository
RevenueService -> ShiftRevenueRepository: 1.4: read submitted collected revenue
activate ShiftRevenueRepository
ShiftRevenueRepository -> ShiftRevenueCollection: 1.4.1: query shiftrevenues or revenuesummaries
activate ShiftRevenueCollection
ShiftRevenueCollection --> ShiftRevenueRepository: 1.4.2: collected revenue records or none
deactivate ShiftRevenueCollection
ShiftRevenueRepository --> RevenueService: 1.4.3: collected revenue
deactivate ShiftRevenueRepository

alt [no records found]
    RevenueService --> RevenueController: 1.5: zero expected and collected revenue
    RevenueController --> AdminWebApp: 1.6: 200 No records to reconcile
else [mismatch detected]
    RevenueService --> RevenueController: 1.5: discrepancy with MINOR_DIFFERENCE or MAJOR_DIFFERENCE
    RevenueController --> AdminWebApp: 1.6: 200 Reconciliation mismatch
else [reconciliation successful]
    RevenueService --> RevenueController: 1.5: MATCHED reconciliation summary
    RevenueController --> AdminWebApp: 1.6: 200 Reconciliation matched
end
deactivate RevenueService
deactivate RevenueController
AdminWebApp --> Admin: 1.7: Display reconciliation result
deactivate AdminWebApp

@enduml
