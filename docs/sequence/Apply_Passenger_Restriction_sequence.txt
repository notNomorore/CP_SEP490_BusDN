@startuml
title Apply Passenger Restriction - Sequence Diagram

hide footbox
skinparam sequenceMessageAlign center
skinparam responseMessageBelowArrow true
skinparam ParticipantPadding 25
skinparam BoxPadding 10

actor Admin
participant "Admin Web App" as AdminWebApp
participant "RestrictionController" as RestrictionController
participant "RestrictionService" as RestrictionService
participant "UserRepository" as UserRepository
database "User Collection" as UserCollection
participant "ViolationRepository" as ViolationRepository
database "Violation Collection" as ViolationCollection
participant "RestrictionRepository" as RestrictionRepository
database "Restriction Collection" as RestrictionCollection
participant "NotificationService" as NotificationService

note over NotificationService
Passenger notification is not implemented in applyRestriction.
The flow applies account lock for ACCOUNT_SUSPENSION and writes an audit log.
end note

Admin -> AdminWebApp: 1: Apply passenger restriction
activate AdminWebApp
AdminWebApp -> RestrictionController: 1.1: POST /api/admin/passenger-restrictions
activate RestrictionController
RestrictionController -> RestrictionService: 1.2: applyRestriction(payload, admin)
activate RestrictionService
RestrictionService -> UserRepository: 1.3: find passenger account
activate UserRepository
UserRepository -> UserCollection: 1.3.1: query user by passengerId
activate UserCollection
UserCollection --> UserRepository: 1.3.2: passenger or null
deactivate UserCollection
UserRepository --> RestrictionService: 1.3.3: passenger account
deactivate UserRepository
RestrictionService -> ViolationRepository: 1.4: find referenced violation
activate ViolationRepository
ViolationRepository -> ViolationCollection: 1.4.1: query violation by id
activate ViolationCollection
ViolationCollection --> ViolationRepository: 1.4.2: violation or null
deactivate ViolationCollection
ViolationRepository --> RestrictionService: 1.4.3: violation record
deactivate ViolationRepository
RestrictionService -> RestrictionRepository: 1.5: check overlapping active restriction
activate RestrictionRepository
RestrictionRepository -> RestrictionCollection: 1.5.1: query active restriction overlap
activate RestrictionCollection
RestrictionCollection --> RestrictionRepository: 1.5.2: overlapping restriction or none
deactivate RestrictionCollection
RestrictionRepository --> RestrictionService: 1.5.3: overlap result
deactivate RestrictionRepository

alt [passenger not found]
    RestrictionService --> RestrictionController: 1.6: passenger not found
    RestrictionController --> AdminWebApp: 1.7: 404 Passenger not found
else [violation not found]
    RestrictionService --> RestrictionController: 1.6: violation not found
    RestrictionController --> AdminWebApp: 1.7: 404 Violation not found
else [restriction already active]
    RestrictionService --> RestrictionController: 1.6: overlapping restriction
    RestrictionController --> AdminWebApp: 1.7: 409 Restriction already active
else [restriction applied successfully]
    RestrictionService -> RestrictionRepository: 1.6: create active passenger restriction
    activate RestrictionRepository
    RestrictionRepository -> RestrictionCollection: 1.6.1: insert restriction
    activate RestrictionCollection
    RestrictionCollection --> RestrictionRepository: 1.6.2: saved restriction
    deactivate RestrictionCollection
    RestrictionRepository --> RestrictionService: 1.6.3: restriction
    deactivate RestrictionRepository
    opt 1.7: ACCOUNT_SUSPENSION restriction
        RestrictionService -> UserRepository: 1.7.1: lock passenger account
        activate UserRepository
        UserRepository -> UserCollection: 1.7.2: update status LOCKED and accountLock
        activate UserCollection
        UserCollection --> UserRepository: 1.7.3: account updated
        deactivate UserCollection
        UserRepository --> RestrictionService: 1.7.4: lock synced
        deactivate UserRepository
    end
    opt 1.8: notification integration missing
        RestrictionService -> NotificationService: 1.8.1: notify passenger of restriction
        activate NotificationService
        NotificationService --> RestrictionService: 1.8.2: not implemented in current source
        deactivate NotificationService
    end
    RestrictionService --> RestrictionController: 1.9: restriction response
    RestrictionController --> AdminWebApp: 1.10: 201 Passenger restriction applied
end
deactivate RestrictionService
deactivate RestrictionController
AdminWebApp --> Admin: 1.11: Display restriction result
deactivate AdminWebApp

@enduml
