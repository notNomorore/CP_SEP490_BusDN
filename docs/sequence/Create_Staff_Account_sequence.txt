@startuml
title Create Staff Account - Sequence Diagram

hide footbox
skinparam sequenceMessageAlign center
skinparam responseMessageBelowArrow true
skinparam ParticipantPadding 25
skinparam BoxPadding 10

actor Admin
participant "Admin Web App" as Web
participant "AdminController" as StaffController
participant "AdminModel" as StaffRepository
participant "SMTP Transport" as NotificationService
database "User Collection" as UserDB

note over StaffController,StaffRepository
Create Staff Account is implemented by AdminController.createManagedUser and AdminModel.createManagedUser; staff records are stored in User.
end note

Admin -> Web: 1: Submit staff account form
activate Web
Web -> StaffController: 1.1: POST /api/admin/users
activate StaffController
StaffController -> StaffController: 1.2: validate fullName, email, phone, role, SMTP config
alt [validation failed or SMTP missing]
    StaffController --> Web: 1.3.1: 400 or 500 error
else [payload valid]
    StaffController -> StaffRepository: 1.4: findUserByIdentifier(email, phone)
    activate StaffRepository
    StaffRepository -> UserDB: 1.4.1: findOne by email or phone
    activate UserDB
    UserDB --> StaffRepository: 1.4.2: existing user or null
    deactivate UserDB
    StaffRepository --> StaffController: 1.5: duplicate result
    deactivate StaffRepository
    alt [duplicate staff account]
        StaffController --> Web: 1.6.1: 409 Email or phone already registered
    else [unique account]
        StaffController -> StaffController: 1.7: generate temporary password and staffMetrics
        StaffController -> StaffRepository: 1.8: createManagedUser(account payload)
        activate StaffRepository
        StaffRepository -> UserDB: 1.8.1: save new User document
        activate UserDB
        UserDB --> StaffRepository: 1.8.2: saved user
        deactivate UserDB
        StaffRepository --> StaffController: 1.9: created user
        deactivate StaffRepository
        StaffController -> NotificationService: 1.10: sendTemporaryPasswordMail(email, temporaryPassword)
        activate NotificationService
        NotificationService --> StaffController: 1.11: mail sent or mail error
        deactivate NotificationService
        alt [email send failed]
            StaffController -> StaffRepository: 1.12.1: deleteUserById(createdUserId)
            activate StaffRepository
            StaffRepository -> UserDB: 1.12.2: findByIdAndDelete
            activate UserDB
            UserDB --> StaffRepository: 1.12.3: deleted user
            deactivate UserDB
            StaffRepository --> StaffController: 1.12.4: rollback complete
            deactivate StaffRepository
            StaffController --> Web: 1.12.5: 502 email failed
        else [email sent]
            StaffController --> Web: 1.13.1: 201 account created, mailSent true
        end
    end
end
deactivate StaffController
Web --> Admin: 1.14: Show create account result
deactivate Web
@enduml
