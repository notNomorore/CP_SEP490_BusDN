@startuml
title Apply Promotion Code - Sequence Diagram

hide footbox
skinparam sequenceMessageAlign center
skinparam responseMessageBelowArrow true
skinparam ParticipantPadding 25
skinparam BoxPadding 10

actor Passenger
participant "Passenger App" as PassengerApp
participant "PaymentController" as PaymentController
participant "PaymentService" as PaymentService
participant "PromotionService" as PromotionService
participant "PromotionRepository" as PromotionRepository
database "Promotion Collection" as PromotionCollection
database "Payment Collection" as PaymentCollection

note over PaymentController, PromotionService
Missing implementation: no passenger checkout endpoint applies a promotion code.
PromotionService supports admin management/statistics only; PromotionUsage is used for reporting.
end note

Passenger -> PassengerApp: 1: Apply promotion code
activate PassengerApp
PassengerApp -> PaymentController: 1.1: POST /api/tickets/payments with promotionCode
activate PaymentController
PaymentController -> PaymentService: 1.2: validate payment payload and promotion code
activate PaymentService
PaymentService -> PromotionService: 1.3: validatePromotionCode(code, userId, order)
activate PromotionService
PromotionService -> PromotionRepository: 1.4: find active promotion by code
activate PromotionRepository
PromotionRepository -> PromotionCollection: 1.4.1: query promotion and usage rules
activate PromotionCollection
PromotionCollection --> PromotionRepository: 1.4.2: promotion record or not found
deactivate PromotionCollection
PromotionRepository --> PromotionService: 1.4.3: promotion lookup result
deactivate PromotionRepository

alt [promotion invalid or expired]
    PromotionService --> PaymentService: 1.5: promotion rejected
    PaymentService --> PaymentController: 1.6: validation failed
    PaymentController --> PassengerApp: 1.7: 400 Promotion cannot be applied
else [promotion eligible]
    PromotionService --> PaymentService: 1.5: discount calculation
    PaymentService -> PaymentCollection: 1.6: update final payment amount
    activate PaymentCollection
    PaymentCollection --> PaymentService: 1.6.1: updated amount
    deactivate PaymentCollection
    PaymentService --> PaymentController: 1.7: payment amount response
    PaymentController --> PassengerApp: 1.8: 200 Promotion applied
end
deactivate PromotionService
deactivate PaymentService
deactivate PaymentController
PassengerApp --> Passenger: 1.9: Show discounted total or error
deactivate PassengerApp

@enduml
