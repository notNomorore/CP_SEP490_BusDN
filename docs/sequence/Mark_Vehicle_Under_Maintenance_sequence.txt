@startuml
title Mark Vehicle Under Maintenance - Sequence Diagram

hide footbox
skinparam sequenceMessageAlign center
skinparam responseMessageBelowArrow true
skinparam ParticipantPadding 25
skinparam BoxPadding 10

actor Admin
participant "Admin Web App" as Web
participant "AdminController" as VehicleController
participant "AdminModel" as VehicleRepository
database "FleetBus Collection" as VehicleDB

note over VehicleController
Maintenance is represented as a normal vehicle update with status MAINTENANCE. No active trip blocker or notification is implemented in AdminController.updateBus.
end note

Admin -> Web: 1: Mark vehicle as maintenance
activate Web
Web -> VehicleController: 1.1: PUT /api/admin/buses/:busId with status MAINTENANCE
activate VehicleController
VehicleController -> VehicleController: 1.2: validate busId and maintenance payload
alt [validation failed]
    VehicleController --> Web: 1.3.1: 400 Bus validation failed
else [payload valid]
    VehicleController -> VehicleRepository: 1.4: updateBusById(busId, payload)
    activate VehicleRepository
    VehicleRepository -> VehicleDB: 1.4.1: set FleetBus.status MAINTENANCE
    activate VehicleDB
    VehicleDB --> VehicleRepository: 1.4.2: updated bus or null
    deactivate VehicleDB
    VehicleRepository --> VehicleController: 1.5: updated bus or null
    deactivate VehicleRepository
    alt [vehicle not found]
        VehicleController --> Web: 1.6.1: 404 Bus not found
    else [maintenance status saved]
        VehicleController --> Web: 1.6.2: 200 Bus updated successfully
    end
end
deactivate VehicleController
Web --> Admin: 1.7: Refresh fleet maintenance status
deactivate Web
@enduml
