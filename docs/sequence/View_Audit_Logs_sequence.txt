@startuml
title View Audit Logs - Sequence Diagram

hide footbox
skinparam sequenceMessageAlign center
skinparam responseMessageBelowArrow true
skinparam ParticipantPadding 25
skinparam BoxPadding 10

actor Admin
participant "Admin Web App" as AdminWebApp
participant "AuditController" as AuditController
participant "AuditService" as AuditService
participant "AuditLogRepository" as AuditLogRepository
database "Audit Log Collection" as AuditLogCollection
participant "UserRepository" as UserRepository
database "User Collection" as UserCollection

note over AuditController, AuditService
Implemented as SystemMonitoringController.getAuditLogs
and SystemMonitoringService.getAuditLogs at GET /api/admin/audit-logs.
end note

Admin -> AdminWebApp: 1: View audit logs
activate AdminWebApp
AdminWebApp -> AuditController: 1.1: GET /api/admin/audit-logs
activate AuditController
AuditController -> AuditService: 1.2: getAuditLogs(filters)
activate AuditService
AuditService -> AuditLogRepository: 1.3: build filter by keyword, role, action, module, status, risk, date
activate AuditLogRepository
AuditLogRepository -> AuditLogCollection: 1.3.1: find logs, count totals, aggregate counts
activate AuditLogCollection
AuditLogCollection --> AuditLogRepository: 1.3.2: audit log records and counts
deactivate AuditLogCollection
AuditLogRepository --> AuditService: 1.3.3: paged audit logs
deactivate AuditLogRepository
AuditService -> UserRepository: 1.4: populate user summaries
activate UserRepository
UserRepository -> UserCollection: 1.4.1: query users referenced by logs
activate UserCollection
UserCollection --> UserRepository: 1.4.2: user summaries
deactivate UserCollection
UserRepository --> AuditService: 1.4.3: safe user data
deactivate UserRepository

alt [no logs found]
    AuditService --> AuditController: 1.5: empty audit log page
    AuditController --> AdminWebApp: 1.6: 200 No logs
else [logs available]
    loop 1.5: Map audit logs with user data
        AuditService -> AuditService: 1.5.1: build audit log response row
        activate AuditService
        AuditService --> AuditService: 1.5.2: mapped row
        deactivate AuditService
    end
    AuditService --> AuditController: 1.6: audit log response
    AuditController --> AdminWebApp: 1.7: 200 Audit logs
end
deactivate AuditService
deactivate AuditController
AdminWebApp --> Admin: 1.8: Display audit log table
deactivate AdminWebApp

@enduml
