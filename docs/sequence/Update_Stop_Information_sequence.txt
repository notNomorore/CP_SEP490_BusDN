actor Admin
participant "Admin Web App" as Web
participant "BusStopController" as BusStopController
participant "BusStopService" as BusStopService
participant "bus-stop.repository" as BusStopRepository
database "RouteStation Collection" as StopDB
participant "MapService" as MapService

note over BusStopController
The backend route exists in busStopRoutes.js but is not mounted in app.js at the time of analysis.
end note

Admin -> Web: 1: Save stop edits
activate Web
Web -> BusStopController: 1.1: PUT /api/bus-stops/:id
activate BusStopController
BusStopController -> BusStopService: 1.2: updateBusStop(stopId, payload)
activate BusStopService
BusStopService -> BusStopRepository: 1.3: findStationById(stopId)
activate BusStopRepository
BusStopRepository -> StopDB: 1.3.1: findById
activate StopDB
StopDB --> BusStopRepository: 1.3.2: existing station or null
deactivate StopDB
BusStopRepository --> BusStopService: 1.4: existing station or null
deactivate BusStopRepository
alt [stop not found]
    BusStopService --> BusStopController: 1.5.1: 404 Bus stop not found
else [stop found]
    BusStopService -> BusStopService: 1.6: merge existing values and validate payload
    opt [address needs geocoding]
        BusStopService -> MapService: 1.6.1: geocodeAddress(address)
        activate MapService
        MapService --> BusStopService: 1.6.2: coordinates
        deactivate MapService
    end
    BusStopService -> BusStopRepository: 1.7: updateStation(stopId, normalized stop)
    activate BusStopRepository
    BusStopRepository -> StopDB: 1.7.1: findByIdAndUpdate
    activate StopDB
    StopDB --> BusStopRepository: 1.7.2: updated station
    deactivate StopDB
    BusStopRepository --> BusStopService: 1.8: updated station
    deactivate BusStopRepository
    BusStopService --> BusStopController: 1.9: updated stop
end
deactivate BusStopService
BusStopController --> Web: 1.10: 200 updated stop or error
deactivate BusStopController
Web --> Admin: 1.11: Refresh stop list
deactivate Web
@enduml
