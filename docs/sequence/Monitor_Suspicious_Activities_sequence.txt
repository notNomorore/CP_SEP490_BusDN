title Monitor Suspicious Activities - Sequence Diagram

hide footbox
skinparam sequenceMessageAlign center
skinparam responseMessageBelowArrow true
skinparam ParticipantPadding 25
skinparam BoxPadding 10

actor Admin
participant "Admin Web App" as AdminWebApp
participant "SecurityMonitoringController" as SecurityMonitoringController
participant "SecurityMonitoringService" as SecurityMonitoringService
participant "AuditLogRepository" as AuditLogRepository
database "Audit Log Collection" as AuditLogCollection
participant "UserRepository" as UserRepository
database "User Collection" as UserCollection

note over SecurityMonitoringController, SecurityMonitoringService
Implemented as SystemMonitoringController.getSuspiciousActivities
and SystemMonitoringService.getSuspiciousActivities. Detection rules live in suspiciousDetection.service.js.
end note

Admin -> AdminWebApp: 1: Monitor suspicious activities
activate AdminWebApp
AdminWebApp -> SecurityMonitoringController: 1.1: GET /api/admin/suspicious-activities
activate SecurityMonitoringController
SecurityMonitoringController -> SecurityMonitoringService: 1.2: getSuspiciousActivities(filters)
activate SecurityMonitoringService
SecurityMonitoringService -> AuditLogRepository: 1.3: query suspicious activity cases
activate AuditLogRepository
AuditLogRepository -> AuditLogCollection: 1.3.1: find suspicious activities and counts
activate AuditLogCollection
AuditLogCollection --> AuditLogRepository: 1.3.2: cases and counts
deactivate AuditLogCollection
AuditLogRepository --> SecurityMonitoringService: 1.3.3: suspicious activity data
deactivate AuditLogRepository
SecurityMonitoringService -> UserRepository: 1.4: populate user summaries
activate UserRepository
UserRepository -> UserCollection: 1.4.1: query related users
activate UserCollection
UserCollection --> UserRepository: 1.4.2: user summaries
deactivate UserCollection
UserRepository --> SecurityMonitoringService: 1.4.3: safe user data
deactivate UserRepository

alt [no suspicious activity]
    SecurityMonitoringService --> SecurityMonitoringController: 1.5: empty suspicious activity page
    SecurityMonitoringController --> AdminWebApp: 1.6: 200 No suspicious activity
else [suspicious activity detected]
    loop 1.5: Group failed login, payment failure, role change, sensitive access cases
        SecurityMonitoringService -> SecurityMonitoringService: 1.5.1: build case response and risk counts
        activate SecurityMonitoringService
        SecurityMonitoringService --> SecurityMonitoringService: 1.5.2: mapped suspicious activity
        deactivate SecurityMonitoringService
    end
    SecurityMonitoringService --> SecurityMonitoringController: 1.6: suspicious activities response
    SecurityMonitoringController --> AdminWebApp: 1.7: 200 Suspicious activities
end
deactivate SecurityMonitoringService
deactivate SecurityMonitoringController
AdminWebApp --> Admin: 1.8: Display monitoring dashboard
deactivate AdminWebApp

@enduml
