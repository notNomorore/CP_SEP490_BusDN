@startuml
title View Ticket Sales Statistics - Sequence Diagram

hide footbox
skinparam sequenceMessageAlign center
skinparam responseMessageBelowArrow true
skinparam ParticipantPadding 25
skinparam BoxPadding 10

actor Admin
participant "Admin Web App" as AdminWebApp
participant "RevenueController" as RevenueController
participant "RevenueService" as RevenueService
participant "TicketRepository" as TicketRepository
database "Ticket Collection" as TicketCollection
participant "WalkInTicketRepository" as WalkInTicketRepository
database "Walk-in Ticket Collection" as WalkInTicketCollection

note over RevenueController, RevenueService
Implemented at GET /api/admin/revenue/ticket-sales-statistics.
The service derives ticket sales from revenue events, travel history, PromotionUsage, and transactions.
end note

Admin -> AdminWebApp: 1: View ticket sales statistics
activate AdminWebApp
AdminWebApp -> RevenueController: 1.1: GET /api/admin/revenue/ticket-sales-statistics
activate RevenueController
RevenueController -> RevenueService: 1.2: getTicketSalesStatistics(filters, admin)
activate RevenueService
RevenueService -> TicketRepository: 1.3: read E-ticket and monthly pass events
activate TicketRepository
TicketRepository -> TicketCollection: 1.3.1: query ticket-related revenue events
activate TicketCollection
TicketCollection --> TicketRepository: 1.3.2: E-ticket and pass events
deactivate TicketCollection
TicketRepository --> RevenueService: 1.3.3: online ticket events
deactivate TicketRepository
RevenueService -> WalkInTicketRepository: 1.4: read walk-in ticket events
activate WalkInTicketRepository
WalkInTicketRepository -> WalkInTicketCollection: 1.4.1: query walk-in ticket records
activate WalkInTicketCollection
WalkInTicketCollection --> WalkInTicketRepository: 1.4.2: walk-in events
deactivate WalkInTicketCollection
WalkInTicketRepository --> RevenueService: 1.4.3: walk-in ticket events
deactivate WalkInTicketRepository

alt [no sales data]
    RevenueService --> RevenueController: 1.5: empty ticket sales statistics
    RevenueController --> AdminWebApp: 1.6: 200 No sales data
else [sales data available]
    loop 1.5: Group by route, date, and ticket type
        RevenueService -> RevenueService: 1.5.1: count tickets and revenue
        activate RevenueService
        RevenueService --> RevenueService: 1.5.2: grouped sales row
        deactivate RevenueService
    end
    RevenueService --> RevenueController: 1.6: ticket sales statistics
    RevenueController --> AdminWebApp: 1.7: 200 Ticket sales statistics
end
deactivate RevenueService
deactivate RevenueController
AdminWebApp --> Admin: 1.8: Display sales charts
deactivate AdminWebApp
